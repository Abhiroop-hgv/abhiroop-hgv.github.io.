github.com/Abhiroop-hgv/CircuitMind ↗

An agentic AI system for semiconductor manufacturing that converts external supply-chain disruptions into actionable procurement plans. It traces each disruption's impact across BOMs and inventory, identifies shortages, and recommends part numbers, quantities, suppliers and dates. Six specialised agents are orchestrated with LangGraph, using MCP for controlled access to enterprise tools and data. A human-in-the-loop interrupt lets a buyer review and approve the plan before any procurement action runs.

LangGraph agent graph
  1. Event ingestionnotice → JSON schema
  2. Exposuresupplier lanes, origin
  3. Shortagestock ledger + forecast
  4. Substitutesrule-engine verdict
  5. Procurementprice × reliability
  6. Human approvalLangGraph interrupt
  • JSON-schema constrained decoding so agents can't emit invalid categories.
  • Compatibility verdicts come from a deterministic rule engine, not the LLM.
  • MCP gives agents controlled access to ERP tools and data, backed by a read-only database role.
  • Output guards replace unsourced figures before display.
  • Live dashboard streams each agent's progress over server-sent events.

ATM Fraud Guard

Winner · Hyderabad Innovation ChallengeTop 25 · NCR Atleos Global Hackathon 2025

A security layer for ATMs that watches the person at the machine. Three vision models run side by side: one matches the user's retina against a database of convicted criminals, one classifies body pose on its own thread to catch suspicious behaviour, and one detects face masks. When the system flags a threat it alerts the nearest police station automatically.

Query-to-Automation RAG

  • Python

Writing automation meant manually finding the right keywords for every step a person described. I built a RAG system that takes a plain-English query, retrieves the matching entries from the automation keyword library, and has an LLM compose the ready-to-run automation keywords. It cuts out the manual lookup and translation work.

A virtual bank teller that customers talk to in their own words. OpenAI Whisper transcribes the spoken request, and a fine-tuned Llama intent classifier maps it to a banking operation, such as a withdrawal, a transfer or a balance check. The teller then performs the transaction on the customer's behalf.

github.com/Abhiroop-hgv/Mission-Store ↗

Drone-based trash detection for a campus. In a web app, the user picks waypoints on a map; the drone flies to each one and photographs the ground. A pre-trained YOLOv5 model runs inference on every image, and any detection with confidence above 0.5 automatically raises a ServiceNow ticket so the facilities team can clean it up.
